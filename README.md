## 📌 Project Overview

The **Student Performance & Behavior Analytics Dashboard** is an interactive Power BI project designed to analyze students' academic performance, attendance, and behavioral patterns.

This dashboard transforms raw student data into meaningful insights using data cleaning, data modeling, DAX calculations, and interactive visualizations.

It helps educators and institutions understand student performance, compare subject-wise results, monitor attendance, and identify behavioral trends.

## 🎯 Project Objectives

- Analyze student academic performance across different subjects and classes.
- Calculate percentage scores and average subject scores.
- Monitor student attendance percentages.
- Understand the distribution of student behavior types.
- Categorize student performance into High, Medium, and Low levels.
- Create an interactive dashboard for student-level analysis.

| Power Query | Data cleaning and transformation |
| DAX | Calculated measures and columns |
| Data Modeling | Relationships between datasets |

## 📂 Project Workflow

### 1️⃣ Data Modeling & Cleaning

- Loaded all datasets into Power BI.
- Created relationships between relevant tables.
- Cleaned column names and corrected data types.
- Handled null and missing values wherever appropriate.
- Prepared structured data for analysis.

### 2️⃣ DAX Measures

Created calculated fields and measures to analyze student performance:

| DAX Measure | Description |
|---|---|
| % Score | Calculates student score percentage |
| Average Score per Subject | Calculates average marks for each subject |
| Attendance % | Measures student attendance percentage |
| Behavior Count by Type | Counts different behavior categories |
| Performance Category | Classifies students into High, Medium, and Low performance groups using SWITCH / IF |

### 3️⃣ Dashboard Visualizations

Designed interactive visualizations to present student insights.

| Visualization | Purpose |
|---|---|
| 📊 Bar Chart | Average scores by Subject and Class |
| 📈 Line Chart | Student performance trends by Term |
| 🍩 Donut Chart | Distribution of behavior types |
| 📋 Table | Student-wise scores with conditional formatting |
| 🃏 KPI Cards | Total Students, Average Attendance, Average Score |

**Conditional Formatting:**
- 🟢 Green: Scores above 80%
- 🔴 Red: Scores below 40%

### 4️⃣ Interactivity Features

Implemented interactive features to improve dashboard navigation and analysis.

- **Slicers:** Class, Section, Subject, and Term.
- **Drill-Through:** Individual student profile with detailed performance information.
- **Tooltips:** Mini charts and additional performance metrics.
- **Bookmark Navigation:** Switch between Academic and Behavioral views.

### 5️⃣ Mobile Layout (Optional)

- Created a mobile-friendly dashboard layout.
- Optimized visual placement for smaller screens.
- Improved accessibility through Power BI Mobile.
